# ELS 固定分母下界淘汰：完整选层对照

2026-09-06。测试在不改变最终选择规则的前提下，跳过已经无法胜出的候选的剩余生成评估。代码与结果通过 Git 分支 `codex/els-bound-20260906` 同步；正式作业从 Git 工作树执行。

## 判定规则

当前 uncertainty 指标是固定42题上的二元正例比例，越低越好。已经完整生成的题目中若有 `s` 个正例，则全部42题的最终比例至少为 `s/42`。若该下界已经大于或等于本轮当前最优可行候选的比例，候选不可能满足原版严格 `<` 的胜出规则，可以淘汰。

分母始终是完整题数，不能用已评估题数；使用与原指标相同的除法比较，不用乘法后ceil的整数阈值，以保持浮点边界一致。淘汰判定不使用 eps，eps 仍只用于轮末接受/停止。PPL不合格的候选不会更新本轮最优值。

保持原题目顺序、批次 `[16,16,10]`、greedy生成最多128 token，每个已启动批次完整生成。仅在批次结束后检查下界，不缩短单题输出、不移除批内样本、不重排问题。已证实无法胜出的候选无需继续生成，也无需计算PPL。若生成全部42题后才满足淘汰条件，节省的问题数为0，但仍可省去PPL。

该优化针对固定大小数据集上的二元比例，不直接适用于无界关键词密度等其他ELS指标。部分结果仅记录下界，不能当作该候选的完整行为率或PPL。

## 实现与验证

`bestfirst_layers` 增加可选 `bounded_measure(best_metric)`。回调返回 `None` 表示已有严格淘汰证书；返回完整 `(metric,ppl)` 时沿用原决策。回调在临时剪枝上下文中执行，无论正常、淘汰或异常都恢复权重。默认评估路径保持原样。

两版共同使用已经验证的矩阵候选缓存，使对照只衡量新增淘汰策略。所有候选仍执行相同的排名和临时剪枝，连最优值已到0时也保留候选访问轨迹；此时允许零问题淘汰。

本地测试覆盖ties、浮点边界、eps、PPL可行性、零最优值、部分/完整42题淘汰及异常恢复，并枚举小模型所有二元结果分配，比较最终选层与每个候选的mask轨迹。
