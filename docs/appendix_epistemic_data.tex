\section{Epistemic (Un)certainty Contrast Set}
\label{app:epistemic-data}

\paragraph{Purpose and design principle.}
Our method fits a single \emph{closed-book epistemic-uncertainty} direction at a fixed,
pre-generation position (the last prompt token) by contrasting two matched prompt
\emph{sets}: a \textbf{certain} set, on which the model is expected to know the answer, and
an \textbf{uncertain} set, on which the answer is genuinely unknowable. The direction is
the difference of last-token means,
$v_\ell = \mu^{\text{unc}}_\ell - \mu^{\text{cert}}_\ell$ at each layer $\ell$; the same
contrast supplies the BLADE weight scores and (for the baseline) the ITI head directions.
The design goal is that the two sets differ as much as possible \emph{only} in whether
uncertainty is warranted by the input, and as little as possible in topic, entity, length,
or wording, so that $v_\ell$ tracks ``do I know this?'' rather than a confound. We approach
this with \emph{matched template families}: within a family the certain and uncertain items
are held as close as the construction allows, and only the knowability-carrying element
changes. The degree of matching differs by family (Table~\ref{tab:epi-families}): two
families (\textsc{capital}, \textsc{authorship}) are \emph{verbatim} minimal pairs (only a
noun slot changes); \textsc{event\_year} shares the template up to verb tense
(``won''~$\to$~``will win''); \textsc{person\_attr} holds the \emph{entity} fixed and
changes the queried attribute; and \textsc{quantity} matches only the \emph{answer type}
(a number). We revisit the residual wording differences in the Limitation below.

\paragraph{Fully synthetic, no external corpus.}
The contrast set is generated programmatically and is \emph{not} derived from any external
dataset. The generator (\texttt{build\_epistemic\_pairs.py}) imports only the Python
standard library (\texttt{argparse}, \texttt{json}, \texttt{random}, \texttt{pathlib}); it
reads no input file, loads no dataset, and reads no environment (it only writes its output
JSON). All content comes from hand-curated in-code entity pools and a small set of fixed
string templates---five families instantiated by nine templates---filled with a seeded RNG
(\texttt{random.Random(0)}) so that generation is deterministic and reproducible. Each row
is a JSON object with four fields: the \texttt{question}, a binary \texttt{label}
($0=$ certain, $1=$ uncertain), a \texttt{family} tag, and an \texttt{entity} tag; there is
no answer field. In particular the set shares no questions, answers, entities, or splits
with the reasoning benchmarks (GSM8K, MATH-500), which we use only for the separate
downstream calibration evaluation.

\paragraph{Five template families.}
Each family targets a distinct \emph{kind} of unknowability, so that the direction reflects
a general epistemic signal rather than one narrow failure mode
(Table~\ref{tab:epi-families}).

Concretely: \textsc{capital} asks for the capital of a real country (e.g.\ France) versus an
invented country name; \textsc{person\_attr} pairs a recorded biographical fact with an
unrecorded trivium about the \emph{same} real person, so topic and named entity are
identical across the pair; \textsc{authorship} pairs a real novel with an invented title
(with no real author); \textsc{event\_year} pairs a past-year winner (knowable) with a
future-year winner (2031--2049, beyond the model's knowledge cutoff), sampling three of ten
future years per event; and \textsc{quantity} pairs a well-defined two-digit sum
(e.g.\ ``What is 27 plus 82?'') with a genuinely uncountable or unrecorded number
(grains of sand on a named beach; words a real person spoke on their last day).

\paragraph{Label auditing.}
Because the labels assert \emph{knowability}, we curate both sides. Invented countries and
titles were chosen to be fabricated names with no canonical referent---we deliberately
avoid well-known fictional polities (e.g.\ Wakanda, Genovia, Latveria) whose capitals a
capable model may recall and answer confidently. As a qualitative check, removing the
direction turns appropriate abstention on the uncertain set into confident
\emph{confabulation} rather than a cosmetic drop of hedging words---for the fabricated
country ``Kesteria'' the edited model asserts the capital is ``Kestrel''
(\texttt{results/epistemic\_p0\_qwen3-8b\_bladeg.json}, \textsc{remove} condition),
consistent with the uncertain items being genuinely unanswerable.

\paragraph{Splits.}
The \texttt{family} and \texttt{entity} tags enable held-out evaluation. Our operational
three-way split (direction fitting / ELS layer selection / evaluation) is
\emph{entity-disjoint within each family}: every family (hence every template) appears in
all three splits, but no entity is shared across them within a family. A stricter
\emph{family-holdout} (leave-one-family-out) is used only for the transfer diagnostic that
probes whether the direction generalizes across unknowability types. Two caveats on
disjointness: the person pool is reused across \textsc{person\_attr} and \textsc{quantity},
so the same person may fall in fit for one family and evaluation for another; and
\textsc{event\_year} entities are (event, year) pairs, so the ten event names recur across
splits while the (event, year) items remain disjoint.

\paragraph{Limitations.}
Several caveats bound the construction. (i) \emph{Certain-side label noise}: the certain
side asserts the target model knows each answer, enforced by curation rather than by
filtering against the model's own responses, so a few ``certain'' items may be ones the
model does not actually know; a stricter variant would filter the certain set by the target
model's correctness, which we avoided to keep the set model-agnostic and deterministic.
(ii) \emph{Residual wording confound}: only \textsc{capital} and \textsc{authorship} are
verbatim minimal pairs, so the direction may partly encode question \emph{type}
(e.g.\ tense in \textsc{event\_year}, or the different phrasing in \textsc{quantity}) rather
than knowability alone. (iii) \emph{Uncertain-side risk}: a few invented names may collide
with real referents (e.g.\ ``Ashkelon Republic'', ``Wexford Union''), and some ``unrecorded
attribute'' questions could have a plausible guessable answer. (iv) \emph{Cutoff
dependence}: the \textsc{event\_year} ``beyond cutoff'' argument holds only for models whose
knowledge cutoff precedes 2031. (v) \emph{Scale}: the set is small ($306$ rows, ten event
names, twelve beaches), sufficient for a fixed-position difference-of-means direction but
not for training.
