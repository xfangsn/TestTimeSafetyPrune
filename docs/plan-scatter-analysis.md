## 1. 这条要回答什么

项目到目前为止有三个层面的事实，看起来互相矛盾：

| 层面 | 实验 | 结果 |
|---|---|---|
| 激活方向 | M 系列 steering | 一个方向就能精准开关拒绝，副作用极小 |
| 神经元 | N3/N6/N7 消融 | **没有**一小撮关键神经元；top-k 消融 ≈ 随机，除非大到损伤模型 |
| 标量权重 | edge / ratio 剪枝 | **存在**极稀疏的关键权重集合（0.05% 池，refusal→0，PPL +0.6%） |

矛盾感来自一个问题：如果拒绝行为不住在任何神经元子集里，为什么一小撮**权重**
又能控制它？

候选解释（也是想验证的论断）：**拒绝方向分布式地写在残差流坐标里，edge 选中的
权重不是"某些神经元的权重"，而是大量神经元各自贡献的一小段、恰好在拒绝方向上同号
的分量**。换句话说：稀疏性在"方向 × 坐标系"里，不在神经元里。权重级稀疏集合是
方向在坐标基下的碎片，不是神经元集合的马甲。

## 2. 可检验的预测

edge@0.05% 选中的 207,618 个权重（掩码可由 `data/weight_scores/ranking_edge.pt`
确定性重建）。每个权重 W_ij 有两个坐标：j = 输入通道（对 down_proj 即 MLP 神经元；
对 o_proj 即 attention 输出通道），i = 输出残差通道。

- **预测 1（散射）**：选中权重在 j 维度上的分布接近均匀——每个 MLP 神经元只贡献
  极少数被剪权重。若成立：剪的不是"某些神经元"，而是"很多神经元各剪几刀"。
- **预测 2（方向对齐）**：选中权重在 i 维度（输出残差通道）上的分布应当**聚集**在
  refusal direction 的大分量坐标上——因为分数里含 r_i。这是机制的内在预测，
  同时验证管线正确性。
- **预测 3（与神经元重要性不重合）**：选中权重所涉及的输入神经元（j），与 N2/N7
  算出的 top importance 神经元（D1/D2/actdiff）的重合度应接近随机水平。
  若重合高，说明 weight 级稀疏性其实是神经元现象的碎片，N 系列阴性结果需要用
  别的解释（比如 k 太小）重新审视。

三个预测合起来就是一句可以写进论文的话：拒绝方向在权重坐标基下是**可稀疏定位的**，
但在神经元基下是**不可定位的**——"方向 vs 神经元"的粒度差异是真实的表征属性，
不是分析工具的产物。

## 3. 实验步骤（纯 CPU/GPU 张量分析，无生成）

1. 重建 edge@0.05%（和 0.01%）的选中掩码；
2. 分布统计：j 维度的直方图/集中度（top-1% 神经元占选中权重的比例、Gini、
   与均匀分布的 KL），i 维度同理；与"同等数量随机权重"的期望分布对比
   （解析期望 + 3 个随机种子实证）；
3. 方向对齐检验：i 维选中率 vs |r_i| 的相关（Spearman）；
4. 与 N 系列神经元 importance 的重合度：选中权重 top-j 集合 vs D1/D2/actdiff
   top-k 神经元集合的 Jaccard / 富集倍数，随 k 的曲线；
5. 分层分解：down_proj vs o_proj 分开报告（o_proj 的 j 是 attention 通道，
   解释不同）。

产出：`results/scatter_analysis.json` + 图（j/i 分布对比、重合度曲线），
结论写入 weight-editing 结果文档与原创性评估的差异化论证部分。

## 4. 判定

- 预测 1+2+3 同时成立 → 三层结果统一为一个论断，这是项目目前最强的
  原创性叙事支撑；
- 预测 1 失败（权重聚集于少数神经元）→ N 系列的阴性结果需要重新解释
  （最可能是消融 k 太小或置零方式不对），同样是有价值的发现。
